Three runs of the same fifty one checks, 2 September 2026, SDK 10.0.400, .NET 10.0.11.
Unedited apart from the headings and the blank lines between the columns.

The browser column is Chrome on osx-arm64 against browser-wasm, read out of the page console.
The desktop columns are the same Probe.cs compiled into a console app, on this laptop and on
server1. Two desktops rather than one so that the desktop answers are CoreCLR's answers and not
one operating system's.

Addresses, hash codes, process ids and allocation counters differ every run and are not the
point. The rows worth reading are the ones where the shape of the answer differs, and
browser-tier.md next to this file goes through all sixteen of them.
